# PaleoCurrNER

**Weakly Supervised Named Entity Recognition for Paleontological Texts**

PaleoCurrNER is a weakly supervised named entity recognition (NER) framework for paleontological literature. It combines large-language-model-based weak annotation, domain-adaptive data augmentation, and span-level curriculum learning to improve coverage while reducing local boundary and type noise.

## Overview

Paleontological texts contain specialized entities with long-tailed names, complex boundaries, and dense cross-type co-occurrence. Dictionary-based distant supervision often misses rare entities or fragments compound names, whereas LLM-generated labels may introduce boundary shifts and type confusion.

PaleoCurrNER addresses these limitations through three consecutive stages:

1. **LLM-based automatic annotation** selects representative texts through cluster-balanced sampling and generates initial weak labels under entity-type, boundary, and JSON-output constraints.
2. **Domain-adaptive augmentation** expands the weakly supervised data through entity replacement, source-text rewriting, and entity combination with style generation.
3. **Span-level curriculum learning** estimates positive-span reliability through multi-model voting and gradually introduces examples from high to low confidence.

## Dataset Summary

| Dataset | Texts | Entities | Purpose | Annotation |
|---|---:|---:|---|---|
| LLM-annotated training set | 25,342 | 94,707 | Initial weak supervision | Automatic LLM annotation |
| Augmented training set | 14,473 | 110,620 | Domain-augmented training | Automatic augmentation |
| Manually annotated test set | 188 | 1,348 | Final evaluation | Manual annotation and verification |

The merged training data contain **39,815 texts** and **205,327 entity labels**. Training and test documents are separated by source document. The test set is used only for final evaluation and does not participate in weak annotation, augmentation, parameter selection, or model selection.

## Method

### 1. Representative-text selection and weak annotation

- Candidate abstracts are encoded with `all-MiniLM-L6-v2`.
- K-means clustering is used for topic-balanced sampling.
- Initial weak labels are generated by an LLM using three contextual examples.
- An independent validation prompt removes unparseable, out-of-scope, or source-inconsistent entities.

### 2. Domain-adaptive augmentation

- **Entity replacement** expands rare names and naming variants using type-consistent dictionary entries.
- **Source-text rewriting** increases contextual and syntactic diversity while preserving entity types and boundaries.
- **Entity combination with style generation** supplements dense multi-type co-occurrence and compound-boundary examples.

### 3. Span-level curriculum learning

- SciBERT encodes each text and candidate spans are classified directly.
- Three voters with different random seeds and bootstrap subsets estimate positive-span confidence.
- Training proceeds through three cumulative curriculum stages, from high-confidence positives to all positive spans.
- Previously introduced positives and all sampled negatives are retained in later stages.

## Main Results

Results below are means over three independent runs with random seeds `13`, `47`, and `59`.

| Model | Strict P | Strict R | Strict F1 | Partial P | Partial R | Partial F1 |
|---|---:|---:|---:|---:|---:|---:|
| BOND | 35.60 | 49.26 | 41.33 | 55.12 | 76.26 | 63.99 |
| Conf-MPU-BERT | 30.24 | 56.60 | 39.42 | 42.29 | 79.15 | 55.13 |
| RoSTER | 35.84 | 50.22 | 41.83 | 54.26 | 76.04 | 63.33 |
| GLiNER2 | 60.86 | 56.53 | 58.62 | 75.16 | 69.81 | 72.38 |
| GLiNER | 65.20 | 57.40 | 61.10 | 77.70 | 68.40 | 72.70 |
| GPT-NER | 52.43 | 53.01 | 52.72 | 71.28 | 72.07 | 71.67 |
| DEER | 74.00 | 66.13 | 69.84 | 85.81 | 76.69 | 80.99 |
| **PaleoCurrNER** | **88.19** | **87.54** | **87.86** | **91.26** | **90.58** | **90.92** |

Strict matching requires exact agreement in entity boundary and type. Partial matching requires the same type and a character-span intersection over union of at least `0.5`. Both criteria use one-to-one matching.

## Reproducibility Notes

The main span recognizer uses the following settings:

- Encoder: `SciBERT (scivocab_uncased)`
- Maximum input length: `512`
- Maximum candidate-span length: `12`
- Negative-to-positive span sampling ratio: `15:1`
- Optimizer: `AdamW`
- Learning rate: `2e-5`
- Weight decay: `0.01`
- Warm-up ratio: `10%`
- Batch size: `8`
- Prediction threshold: `0.3`

All parameters were fixed from related work, task priors, and the available computational budget before examining test results.
